Packet Tracer Lab

Cisco Networking & Simulation Labs

View the lab repository (opens in a new tab)

Repository: adu0723/cisco-networking-academy-lab

Self-directed Cisco Packet Tracer labs that build a small-office/home-office (SOHO) network end to end: assembling the topology, bringing up the wireless router, and verifying that every client receives a working address.

What I configured

  • Built the SOHO topology in Packet Tracer and configured the wireless router through its GUI setup screens.
  • Secured the wireless network with WPA2-Personal, setting the authentication and passphrase options.
  • Configured the router's DHCP pool and confirmed connected clients received valid leases.
  • Applied basic IPv4 addressing and subnetting, then tested client-to-router connectivity.

How I troubleshooted

  • Worked bottom-up through the layers: interface status first, then addressing, then reachability tests.
  • Checked interface state, DHCP lease tables, and each client's IP configuration to isolate the failing hop.
  • Re-tested after every change so a fix was confirmed rather than assumed.
